# 静静 使用手册

> README 讲"她是什么、怎么装"；这份讲**"装好之后怎么用、她到底怎么工作、出问题看哪儿"**。
> 想改代码看 [`二次开发`](#8-二次开发)；只想把她跑起来，跳到第 [2](#2-从零跑起来) 节。

---

## 0. 一句话理解她

她**不是**一个"接了大模型的自动回复机器人"。她是：

- **一个有长期记忆、会自己动手的角色**：记忆存在 SQLite（带重要度、关联、衰减），
  能自己调工具（画图、查记忆、读文件、跑 shell、看屏幕、上网）；
- **一个意识，三个入口**：QQ、桌面宠物、后台面板都是她伸出去的手——
  她在 QQ 里和在桌面上用的是**同一套人格、同一段记忆**，不是"两个静静"；
- **可以被主人指挥干活**：文件沙箱里她能创建/整理/运行东西，也能在群里帮忙查资料。

---

## 1. 三个入口

| 入口 | 怎么进 | 适合干什么 |
|---|---|---|
| **QQ**（主入口） | 私聊她 / 在群里 @她 / 用触发词 | 日常聊天、群里接梗、让她干活（写文件、画图、查资料） |
| **桌面宠物**（DesktopPet） | 双击仓库根的 `启动静静.bat` | 她坐在桌面上陪你：气泡说话、陪玩（游戏模式）、看屏幕 |
| **后台面板** | 浏览器开 `http://127.0.0.1:7088/`（默认端口） | 调她的配置/提示词/记忆/工具，看日志与统计 |

### 三条通道的差别（她自己也清楚这一点）

| | QQ 私聊 | QQ 群 | 桌面宠物 |
|---|---|---|---|
| 会话历史 | 独立一段 | 每群独立一段 | **默认独立一段**（`Pet.SessionKey` 可改成和 QQ 私聊共用） |
| 她怎么称呼你 | 「主人」 | 「主人」（她能认出是谁说的） | 「主人」 |
| 消息怎么到她那儿 | NapCat → WS 事件 | 同左 | HTTP `POST /api/pet/chat` |
| 她主动找你 | 私聊消息 | 群里发言 | **气泡**（桌宠在线且你在电脑前）；否则自动改走 QQ |

> 她主动找你的逻辑：`send_private_to_owner` 会看**桌宠是否在线 + 你是否在电脑前**——
> 你在桌前就弹气泡，人走开了就发 QQ。你不用操心，她自己选。

## 2. 从零跑起来

### 2.1 环境要求

| 需要 | 说明 |
|---|---|
| Windows 10/11 | 机器人本身跨平台，但 NapCat 与桌宠是 Windows 的东西 |
| .NET 10 SDK | 编译与运行（`dotnet --version` 能出版本号即可） |
| 一个 QQ 小号 | **别用主号**，风控了会心疼（建议养一段时间再用） |
| LLM API Key | 默认 DeepSeek，任何 OpenAI 兼容服务都行（改 `Llm.BaseUrl`） |
| ComfyUI（可选） | 本地生图用；不装的话画图工具会报错，其它功能不受影响 |

### 2.2 先把 NapCat 跑起来

NapCat 是"协议端"，负责把 QQ 的消息转成 OneBot 11 事件喂给机器人。
详细步骤见 [`docs/NapCat安装教程.md`](NapCat安装教程.md)，要点：

1. 启动 NapCat（它会拉起绿色版 QQ）→ 扫码登录小号；
2. 确认三个端口在听：**3000**（HTTP，用来发消息）、**3001**（WS，用来收事件）、**6099**（WebUI，配置用）；
3. 别关 NapCat 的窗口——关了就掉线。

### 2.3 填配置（`src/QQBot/appsettings.json`）

只有几处是**必须改**的：

| 字段 | 填什么 |
|---|---|
| `Bot.OwnerId` | **你自己的 QQ 号**（最高权限：管理员命令、隐私工具都认它） |
| `Bot.SelfId` | 机器人那个小号的 QQ 号 |
| `Bot.Llm.ApiKey` | 你的 API Key |
| `Bot.Admin.Token` | 面板访问令牌（**改成自己的**，别留 `change-me`，更别留空） |
| `Bot.Prompt.Owner.SystemPrompt` | 她的人设（**这里决定她的性格**，仓库里带的是一份示例） |

其余字段都有注释，边看边调即可。**改完配置要重启进程**（`scripts/restart.bat` 会自动把配置同步到运行目录再启动）。

### 2.4 启动

```bat
QQBot\scripts\restart.bat      :: 停止 → 同步配置 → 启动（改完配置用这个）
QQBot\scripts\start.bat        :: 只启动
QQBot\scripts\stop.bat         :: 只停止
```

看到这两行就算上线了：

```
已连接机器人账号：静静 (你的机器人QQ)
WebSocket 已连接 ✓
```

桌宠是另一件事，见 [`src/DesktopPet/README.md`](../src/DesktopPet/README.md)。

### 2.5 打开面板

浏览器访问 `http://127.0.0.1:7088/`，第一次会让你填令牌（就是 `Bot.Admin.Token`），
填一次后存在浏览器本地，之后不用再填。

> ⚠️ **面板只监听本机**。想远程访问的话，自己套一层反向代理 + 认证，别直接把端口暴露到公网。

## 3. 跟她说话会发生什么

### 3.1 一条消息的完整旅程

```
QQ/NapCat 事件
   ↓
① 触发判断：私聊主体？@她？命中触发词？命中命令（! 前缀）？
   ↓
② 忙时合并：她正在处理上一条时，新的消息不会丢，会攒起来合并成一次（MergeSeconds）
   ↓
③ 组装上下文：人设(全局前置 + 场景 Profile) + 在场的人 + 记忆召回 + 上一轮规划 + 引用消息 + 图片(识图)
   ↓
④ 规划轮（可关）：先想"这次要不要欲擒故纵/转移话题"，规划只影响她自己的输出，不发给用户
   ↓
⑤ Agent 工具循环：她可以连续调工具（查记忆、读文件、画图、看屏幕…），最多 MaxToolRounds 轮
   ↓
⑥ 回复数组：她的回复可以是**多条**（`Reply.MaxRepliesPerTurn`，默认最多 4 条），逐条间隔发出去
   ↓
⑦ 记忆落库：对话进历史 → 自动提取值得记的条目 → 挂上关联边与重要度
```

各步骤都能在面板里调：提示词在「提示词」页，记忆参数在「开关」与「记忆」页，工具开关在「Tools 管理」页。

### 3.2 工具（她能自己动手做的事）

| 工具 | 干什么 | 备注 |
|---|---|---|
| `get_time` / `browse_web` | 查时间、上网查东西 | 常开 |
| `search_memory` / `remember` / `organize_memory` | 查/写/整理记忆 | 空关键词查 = 盘点自己记住了什么 |
| `get_chat_history` | 翻聊天记录 | 群聊里用它对齐语境 |
| `read_file` | 读她小空间里的文件 | 支持分段读，不用一次读整个大文件 |
| `run_shell` | 在她的小空间里执行命令 | **沙箱是"防呆不防黑"**，别对陌生人开放 |
| `generate_image` | 调 ComfyUI 画图 | 支持多工作流，她自己按描述选 |
| `capture_screen` | 截屏 + 识图看你在干嘛 | **主人专用**，图片会存进她的空间 |
| `send_private_to_owner` | 主动找主人（气泡或 QQ） | 渠道自动判断 |
| `send_group_message` | 在群里发言 | 自主活动时可关 |
| `send_text` / `send_private_message` | 当场回话 / 私聊某人 | — |

面板「Tools 管理」可以：改工具描述（影响她什么时候用）、禁用某个工具、设客人白名单。

### 3.3 烧token模式（正式回复前的"静默准备"）

普通流程是"她一收到消息就得开始回答"。这个模式会**在正式回复前插一段静默收集阶段**：

- 起始只给她「人设 + 基本提示词 + 唤起原因」，**不注入历史与记忆**；
- 她自己决定去查什么（`get_chat_history`、`search_memory`、`read_file`…），思考轮的正文一律不发送；
- 她觉得准备好了，调 `ready_to_reply` → 那一轮才算正式回复；
- 回复发出后还有一轮**自评 + 记忆整理**（同样不发出去）。

代价是**慢**（一条消息可能等 1-3 分钟）且贵。适合"重要对话/需要查证"的场景，聊天打屁时开着只会让她变迟钝。
开关与参数在面板「烧token模式」组。详见 [`docs/烧token模式.md`](烧token模式.md)。

### 3.4 三模式联动（游戏 / 一般 / 看家）

机器人**每 30 秒采一次主机状态**（键鼠空闲、前台窗口、GPU、独占全屏、Steam 正在跑的游戏），
自动判断你现在处于哪种状态，然后改变她的节奏与行为：

| 模式 | 怎么判定 | 她怎么变 |
|---|---|---|
| **一般** | 默认 | 照常：该干什么干什么，间隔 `AutoActivity.IntervalMinutes` |
| **游戏** | Steam 有游戏在跑 / 前台独占全屏 / GPU 超阈值 | **陪玩**：间隔很短（默认 3 分钟），只干"看他屏幕 + 说一句话" |
| **看家** | 键鼠静默超过 `AwayAfterMinutes`（默认 10 分钟） | 她**知道你看不见气泡**，要联系你就走 QQ；这段时间是她打理自己的时间 |

**游戏模式有一套独立的精简管线**（因为它最花钱）：

- 用**独立提示词**（面板「活动模式」组里的"游戏模式专属提示词"，默认内置那份可随意改）；
- **只保留白名单里的工具**（默认 `send_private_to_owner` + `get_time` + `capture_screen`）；
- **不注入**长期记忆档案、记忆库、主人聊天、群状态（陪玩用不上，纯烧钱）；
- 用**自己的小本子** `data/workspace/游戏模式记忆.md`，活动结束只**追加一两句**（不重写全文）；
- 单次活动轮数上限很低（默认 4），说完就收工。

这些都是"游戏模式专用"的开头，不影响一般/看家模式。

面板「活动模式」组底部还有 **`ForceMode`**：填 `game` / `normal` / `away` 可强制锁定模式，
调试或临时改行为时非常好用（改完记得放回 `auto`）。

## 4. 记忆系统

### 4.1 记忆库（SQLite）

- 每条记忆有**归属**：`global`（通用）/ `user`（某人）/ `group`（某群）；
  归属按**信息主体**判断——"某某喜欢猫"记给某某，而不是记给说话的人；
- 有**重要度**（★1-5）：高重要度的每次都注入（`AlwaysInjectImportance`）；
- 有**关联边**：记忆之间连成网，查一条会顺带召回相邻的（`MaxLinkHops`）；
- 会**衰减**：久了没用会慢慢降权（`DecayPerDay`），被用到会加权（`BoostOnUse`）。

面板「记忆」页可以增删改查，「记忆图谱」页把这张网画出来。

### 4.2 长期记忆档案（Markdown）

一份她**自己维护**的 Markdown（默认 `data/workspace/长期记忆.md`），
每次自主活动时**全文交给她**，活动结束再让她更新。

> 为什么要这个：她不用每次都去 `dir` 翻文件夹找"我把东西放哪了"。
> 档案够全，她就不需要翻文件——**用上下文换工具调用**。

⚠️ 档案会越长越大（几万字），每一轮都要重发给模型。面板「自主活动」组有
`LongMemoryMaxChars` 限长；她读不了尾部的老内容时，考虑让她自己精简（或参考
[`docs/上下文瘦身方案.md`](上下文瘦身方案.md)）。

### 4.3 游戏模式小本子

游戏模式**不用**上面那份大档案，而是 `data/workspace/游戏模式记忆.md`：
短、只记一两句、更新方式是**追加**（她只输出新增内容，程序 append 到末尾，带时间戳）。

### 4.4 图片与元数据

聊天里的图片会被压缩后存进她的空间（`data/workspace/images/`，文件名带来源与时间）。
若开启 `Vision.SaveMetadata`，还会从**原图**里抽文本元数据（PNG `tEXt` / JPEG EXIF 注释）
写成同名 `.txt`——这样 AI 图里藏的 prompt、参数、工作流她也能读到。

> 注意：压缩一定丢元数据，所以抽取必须用原图；而且 QQ 若转压过图片，元数据到不了机器人，
> 这种情况下没有 `.txt` 是正常的。

## 5. 后台面板逐页说明

| 页面 | 干什么 | 常用点 |
|---|---|---|
| **统计** | 消息量趋势、会话数、记忆数、模型与在线状态 | 看"她今天忙不忙" |
| **开关** | 各功能模块总开关 | 生图、识图、自主活动、面板、桌宠接口等 |
| **提示词** | 全局前置/后置 + 主人/客人人设 + 4 个场景 Profile | **改她性格就来这儿**；改完即时生效（热更新） |
| **记忆** | 记忆库增删改查 | 搜关键词，调重要度，删错记的东西 |
| **记忆图谱** | 记忆之间的关联网络可视化 | 看她的知识怎么连起来的 |
| **Tools 管理** | 每个工具的描述/启用/客人白名单 | 她说工具用得不顺手，就在这儿改描述 |
| **!命令控制台** | 在面板里直接执行 `!` 命令 | 不用开 QQ 就能试命令 |
| **Debug 日志** | 实时看她与模型之间的完整请求/响应 | 排查"她为什么这么答"的**第一现场** |
| **评测** | 提示词改动前后的一致性对比 | 调提示词别把老能力调坏 |
| **群管理** | 群列表、群黑名单、成员校验 | 不想理某群就拉黑 |
| **桌面精灵** | 桌宠的皮肤/气泡/动作/工具绑定 | 见桌宠 README |
| **活动模式** | 三模式判定阈值 + 游戏模式的独立管线 | 见 [3.4](#34-三模式联动游戏--一般--看家) |

**热更新**：提示词、开关这类改完点保存就生效；**代码层的东西（新增配置项、工具、逻辑）必须重启**。

## 6. 常见问题

| 现象 | 先看哪儿 |
|---|---|
| 她完全不回话 | ① NapCat 窗口还在吗（3000/3001 端口）② 日志里"WebSocket 已连接 ✓"有吗 ③ 是不是在群里但没触发（私聊/@/触发词/命令四选一） |
| 回复特别慢 | 看「Debug 日志」：是不是在跑规划轮/烧token模式的收集阶段/工具循环；模型超时也会重试 |
| 面板打不开（502/超时） | **是不是开着代理/VPN**——把 `127.0.0.1` 加进直连规则；本地服务不该走代理 |
| 面板 401 | 令牌填错了（`Bot.Admin.Token`）；浏览器本地存的旧令牌要清掉 |
| 桌宠站着一动不动 | 看 `%USERPROFILE%\.jingjing-pet\pet.log`：动作帧是不是没配/文件不存在（配了却找不到会明确报警） |
| 桌宠点不到（鼠标穿透） | 她判定"你在游戏模式"时会整只穿透（防误触）。想点她：面板「活动模式」把 `ForceMode` 设成 `normal` |
| 生图失败 | ComfyUI 在跑吗（默认 8188）；工作流节点 ID 对不对（面板「生图 → 工作流说明」可自检） |
| 频繁掉线 | 大概率是 QQ 风控前兆，停用半天，别硬刚 |
| 记忆记错了人 | 看「记忆」页的归属（`user`/`group`/`global`）；归属按信息主体判断，措辞含糊时她会猜错 |

## 7. 二次开发

### 7.1 新增一个工具

1. 在 `Core/Tools/` 下实现 `ITool`（`Name` / `Description` / 参数 schema / `ExecuteAsync`）；
2. 在 `BuiltinTools.CreateAll` 里注册（要放自主活动也能用的话，还要加进 `BuildActivityTools`）；
3. 涉及隐私的工具记得 `OwnerOnly => true`。

### 7.2 新增一个配置项（三处一起改，缺一处就出 bug）

1. `Core/Options/BotOptions.cs`：加属性 + **默认值**；
2. `Core/Admin/AdminService.cs`：加进 `ConfigGroups`（通用配置页）或 `PromptDefs`（提示词页）；
3. `src/QQBot/appsettings.json`：加键 + 中文注释。

⚠️ **只写代码默认值而不进 appsettings**：面板读到的是 `null`，用户一保存就把值写空了。
要给用户看的配置**必须落到 appsettings**。

### 7.3 面板加一个页面

单文件 `wwwroot/admin.html`：加 `<a data-page="xxx">`、加 `<section id="page-xxx">`、
在切页逻辑里挂上加载函数即可（无需前端构建工具）。
